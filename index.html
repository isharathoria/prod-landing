How it works

From “that looks off” to merged, in three steps.

1

Pin it

Anyone clicks the problem on the live site and types a sentence. Screenshot, element, console and device details are captured for them.

2

Brief it

The agent asks a quick question if needed, then writes what's wrong, what should happen, the exact change and how to check it.

3

Ship it

Your coding tool pulls the brief over MCP, a developer picks up the ticket, or the agent opens a draft PR.
